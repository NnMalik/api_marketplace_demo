
  # API Marketplace Simulator Design

  This is a code bundle for API Marketplace Simulator Design. The original project is available at https://www.figma.com/design/LpVE5xRjBqY8BbzP4OwDc2/API-Marketplace-Simulator-Design.

## Running the code

Run `npm i` to install the dependencies.

Run `npm run dev` to start the development server.

## Deployment to GitHub Pages

The frontend is deployed to GitHub Pages:

**Live URL:** [https://NnMalik.github.io/api_marketplace_demo/](https://NnMalik.github.io/api_marketplace_demo/)

### How to deploy

1. Install the deployment tool:
  ```sh
  npm install --save-dev gh-pages
  ```
2. Build the project:
  ```sh
  npm run build
  ```
3. Deploy to GitHub Pages:
  ```sh
  npm run deploy
  ```

The deployment script will publish the contents of the `build` directory to the `gh-pages` branch, making your app available at the URL above.
